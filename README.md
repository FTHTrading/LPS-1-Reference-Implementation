## Local Verification & Build Pipeline

Verify the mathematical integrity of the manuscript locally:

### 1. Install dependencies
```bash
npm install
```

### 2. Compile and Hash Manuscript
This concatenates the manuscript files deterministically and computes their hashes and Merkle roots:
```bash
npm run build
```

### 3. Run Independent Verifier
Confirm that every hash and proof matches the manifest:
```bash
node verifier/lps-verify.js
```
