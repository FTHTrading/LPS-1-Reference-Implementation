## About This Work

*The Protocol Garden* is a sample work created for the LPS-1 Reference
Implementation. It is not a real book. It exists to demonstrate the
deterministic publishing pipeline.

## Colophon

- **Pipeline:** LPS-1 Reference Implementation v1.0.0
- **Hash Algorithm:** SHA-256
- **Merkle Scheme:** Ordered concatenation, odd-leaf duplication
- **Encoding:** UTF-8 with CRLF normalization
- **License:** MIT

## Verification

```
npm run build
npm run verify
```

Every hash, every Merkle root, every proof is independently reproducible.
